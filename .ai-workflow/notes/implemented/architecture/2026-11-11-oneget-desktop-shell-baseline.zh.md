# Agent Note: OneGet 桌面外壳基线

Status: implemented

[English](2026-11-11-oneget-desktop-shell-baseline.md) | 中文

## Problem

OneGet 在构建下载、扩展、视频或发布功能之前，需要一套可信的桌面基础。该外壳必须能在 macOS 和 Windows 上以单窗口启动，提供诊断界面，安全接收深链接，并集成托盘、开机自启、通知和平台凭据存储，同时建立后续功能无法绕过的文件系统与日志边界。若没有记录在案的决策，后续工作可能重新集中平台分支、写出能力根目录、记录凭据材料，或引入远程资源与遥测。

## Decision

交付基线是一个 Tauri 2 桌面应用，使用 React 19 与 TypeScript 6 构建用户界面，Vite 8 负责构建，Rust 后端通过 Cargo 锁定依赖。React 层负责外壳、设计系统基础组件和诊断界面；它只通过带类型的命令包装器调用后端，并把缺少 Tauri 运行时的情况视为 `runtime_unavailable` 而不是崩溃。Tauri 命令层负责应用信息、设置、深链接状态、诊断用密钥往返、通知与自启诊断，以及优雅退出。事件使用 `app://deep-link`，Rust 负载使用 camelCase 和带类型的 `{ code, message }` 错误。

所有目标平台相关行为都限制在平台层：应用路径、文件名清理、能力约束文件操作、受控子进程、密钥存储、深链接、托盘、自启和通知。共享模块只依赖这些接口。文件写入通过以规范目录为根的 `CapDir` 进行，并拒绝绝对路径、父级穿越、NUL 字节、符号链接目标和链接逃逸；异步接口通过 `spawn_blocking` 执行。文件名在使用前会按 macOS 或 Windows 规则归一化并清理。

信任边界是明确的。WebView 使用限制性内容安全策略，不允许远程脚本或远程连接源；资源全部打包，且没有分析或遥测。深链接属于不可信输入，仅允许单个 `oneget://download` 链接，其中包含一个 `http` 或 `https` 目标，不允许内嵌凭据，要求百分号编码合法，并限制为 8 KiB。凭据仅存放在操作系统凭据存储中，通过带类型的密钥接口访问；值在格式化时被遮盖，并在释放时清零；诊断命令只返回布尔值而不返回值本身。组件清单使用规范 JSON 和 Ed25519 `verify_strict` 验证；验证器排除顶层签名字段，拒绝重复键和超大输入，且不增加安装器、下载器或执行路径。

日志写入 JSON 行，包含时间戳、级别、事件和已遮盖字段，按 10 MiB 在五个文件间轮转，并在调试构建中镜像到 stderr。设置使用 schema 版本 1，保留未知字段，原子保存，损坏文档会备份，未来版本 schema 按只读处理。凭据值不会写入设置或日志。

## Alternatives considered

普通 Web 应用或 Electron 外壳被否决，因为可远程访问的运行时和更大的更新面会扩大信任边界。使用环境文件系统 API 而不是能力根目录被否决，因为路径校验会依赖每个调用方。把凭据存入设置或本地加密文件被否决，因为操作系统凭据存储已经提供平台边界和用户控制。在此变更中实现下载、扩展、视频、更新和发布流水线被否决，以便先建立并验证外壳边界。

## Consequences

后续功能必须调用已记录的命令和事件，把目标平台相关代码留在平台层，并让每次文件写入经过能力层。新的网络或资源行为必须保持无遥测规则和限制性内容安全策略。凭据值必须远离设置、日志、诊断负载和前端状态。深链接处理必须继续拒绝格式错误、携带凭据、重复、非 http 以及超长链接。

已交付的本地证据覆盖前端质量门禁、Rust 单元与集成测试、能力与链接逃逸测试、清单接受与拒绝用例、文件名对抗用例、进程树终止、密钥存储假实现、日志遮盖与轮转、设置恢复、深链接解析，以及在仓库外临时目录完成并通过缺失输入失败关闭验证的本地自签名证书创建、导入、验证与清理流程。托管 CI、手动平台验收以及 Windows 与 Intel 检查仍然延后；基线不声称这些结果。下载、扩展、视频、发布签名、公证、更新器和遥测工作不在本基线范围内。
