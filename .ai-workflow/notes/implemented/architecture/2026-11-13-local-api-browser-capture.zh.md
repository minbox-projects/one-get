# Agent Note: 回环浏览器捕获与浏览器扩展集成

Status: implemented

[English](2026-11-13-local-api-browser-capture.md) | 中文

## Problem

OneGet 此前只能在用户把 URL 复制到桌面应用后下载文件。浏览器用户需要一条从已观察页面资源与浏览器下载直达 OneGet 的路径，同时不暴露网络服务、不发明第二套凭据系统，也不允许网页驱动桌面端。缺失的决策包括：如何安全配对 Chromium 扩展，浏览器下载如何恰好变成一个桌面任务，捕获到的资源如何进入下载对话框而不直接启动，页面观察应放在哪里，资源数据可以保留多少，以及在尚不支持下载流媒体清单时应如何展示它们。桌面外壳、下载引擎和下载界面记录确立了本能力所扩展的进程、引擎、存储和界面边界：[OneGet 桌面外壳基线](2026-11-11-oneget-desktop-shell-baseline.md)、[下载引擎与持久任务存储](2026-11-12-download-engine-task-store.md) 和 [桌面下载界面与引擎服务](2026-11-13-desktop-download-ui.md)。[Firefox 扩展对等记录](2026-11-13-firefox-extension-parity.md) 把同一边界扩展到第二种浏览器，并拥有共享控制器、Firefox 包和事件页决策。

## Decision

浏览器边界是一个仅绑定 `127.0.0.1:37652` 的 HTTP 服务，随应用启动，并在引擎之前停止。它是增量且可选的：端口被占用或配对数据库不可读时，浏览器集成不可用，而下载、任务和设置继续工作。健康发现无需认证，但要求精确的回环授权，并拒绝任何存在的非扩展来源。写路由要求精确的浏览器扩展来源——`chrome-extension://` 加 32 个 `a`–`p` 字符，或 `moz-extension://` 加小写 8-4-4-4-12 UUID——在需要请求体时声明 JSON 内容类型，以及绑定到该精确来源的 bearer 令牌。本记录拥有准入、配对、捕获、预填充和隐私决策；[Firefox 扩展对等记录](2026-11-13-firefox-extension-parity.md) 拥有跨浏览器控制器和 Firefox 事件页行为。令牌只从 `Authorization` 头读取，服务不返回通配 CORS 头，并且在任何任务或预填充存在之前执行请求体、条目、URL、头、协议和速率限制。

配对使用专门的 `pairing.db`，而不是任务存储。它只存储代码和令牌的 SHA-256 哈希，以及精确绑定的来源、标签和时间戳。八位代码有效十分钟、只能使用一次，并会被更新的代码替换；五次失败尝试会锁定配对五分钟。成功交换只返回一次 256 位令牌。撤销会删除客户端，删除配对数据库会撤销所有客户端，同时不影响任务、已完成文件或设置。把数据库分开可以让配对状态不进入任务 schema，使撤销成为一次本地删除，并让不可用或未来版本的配对 schema 只降级浏览器集成而不危及下载数据。

捕获协议版本 1 有两种意图。接管请求恰好包含一个条目，恰好创建一个桌面任务，并按令牌绑定的浏览器来源标识去重，因此重复事件（包括 service worker 重启后）会返回已有任务。扩展先发送捕获，再取消并擦除浏览器下载，因此桌面端不可达或捕获失败时浏览器下载保持完整。预填充包含一个或多个条目，不创建任务，并在内存中保存一个有界的待处理列表。桌面端通过事件加打开时拉取命令交付它，在另一个对话框打开时延后，在关闭对话框或重启时丢弃。只接受 URL、文件名、referer、MIME 类型、大小、文件种类，以及安全的 `Referer`、`User-Agent`、`Accept` 和 `Accept-Language` 头；Cookie、authorization 值、任意头、带凭据的 URL 和不支持的 kind 都会被拒绝。

扩展把纯逻辑与浏览器运行时分开。`extension/shared` 保存与浏览器无关的后台控制器、类型化适配器、协议、分类、清单识别、分段过滤、页面归属、有界存储、设置校验、双语文案、隔离内容脚本、MAIN-world 观察器和覆盖层样式，因此这些规则无需浏览器即可单元测试。`extension/chromium` 保存 Chromium MV3 清单和薄 service worker 安装器，`extension/firefox` 保存 Firefox MV3 清单和事件页适配器，`extension/popup` 保存资源、配对和设置视图；[Firefox 扩展对等记录](2026-11-13-firefox-extension-parity.md) 记录该拆分。MAIN-world 脚本必须包装页面的 `fetch`、XHR 和历史 API，才能看到不会到达 `webRequest` 的请求，但它没有扩展权限，只向隔离内容脚本发送 URL、MIME 类型和大小元数据。隔离脚本拥有所有特权行为和覆盖层。

资源数据保持有界且仅限会话。每标签页存储按去掉 fragment 的 URL 去重，每标签页最多 500 个条目、最多 50 个标签页，并在 frame 导航或子 frame 的 SPA 路由变化时清除发起该导航的 frame、在顶层 frame 的标签页导航或 SPA 路由变化时清除整个标签页、在标签页关闭时清除该标签页。service worker 或事件页重启后，后台运行时从有界的会话存储快照恢复。配对令牌和设置是唯一持久的扩展数据，位于本地存储。分类先按文件名扩展名、再按 MIME 类型推导类别。HLS 和 DASH 清单会列出但永不接管，也永不为了解析而抓取；`.ts`、`.m4s`、`.m4f`、`.cmfv`、`.cmfa`、`init.mp4` 和媒体 `videoplayback` 分段 URL 会被过滤。接管还会遵循启用状态、类别开关、精确或子域黑名单主机、隐身与扩展自身发起的下载、非 HTTP URL，以及不适用于未知大小的最小大小限制。

隐私和内容安全策略是决策的一部分，而不是后续加固。MV3 清单只请求 `webRequest`、`downloads`、`storage`、`tabs` 和 `webNavigation`，以及 HTTP(S) 和回环主机权限。它不请求 Cookie、原生消息、远程代码或遥测。扩展页面 CSP 为 `script-src 'self'`，构建打包所有运行时代码，展示的 URL 会移除凭据、查询和 fragment。桌面命令从不返回令牌，也从不显示令牌。覆盖层只在顶层 frame 运行，复用一个按钮，并说明视频解析尚不可用。

## Alternatives considered

- 把浏览器服务绑定到所有网卡或暴露远程端点被否决，因为该能力本质上是本地的，更宽的绑定会创造产品不需要的认证与攻击面。
- 明文存储 bearer 令牌或配对代码被否决，因为复制数据库就会获得捕获权限；SHA-256 哈希既支持查找和撤销，又不留下可重放的秘密。
- 复用任务数据库存储配对被否决，因为浏览器配对具有不同的生命周期、schema 和失败模式，配对迁移不应危及任务数据。
- 接受任何持有有效令牌的扩展或网页来源被否决，因为被盗令牌随后可在另一个客户端使用；把令牌绑定到精确来源使凭据与其持有者保持在一起。
- 为了兼容性捕获 Cookie 或 authorization 头被否决，因为桌面端已把这些值视为秘密，而浏览器掌握其作用域和生命周期。
- 收到预填充后自动开始下载被否决，因为用户必须选择目标、文件名和控制项；预填充对话框保留现有确认边界。
- 在桌面确认任务之前取消浏览器下载被否决，因为捕获失败会丢失文件；先捕获后取消让浏览器下载成为回退。
- 把页面资源持久化到 `storage.local` 或现在就解析视频清单被否决，因为页面内容是敏感的，而视频下载属于后续能力；仅会话的有界列表和禁用的清单操作避免这两种暴露。

## Consequences

任务存储和设置保持 schema 版本 2；配对拥有自己的版本 1 数据库。后续工作必须保留仅回环绑定、固定准入顺序、仅哈希令牌、精确浏览器扩展来源绑定、一次性代码与锁定规则、令牌绑定去重、先捕获后取消接管，以及单一内存预填充。来源边界接受精确的 Chromium 标识符形式和精确的小写 Firefox UUID 形式；不得扩大到任意扩展字符串或跨方案令牌。新的捕获字段或 kind 需要协议变更，并必须让凭据值远离请求和存储。新的扩展观察必须留在 MAIN-world 观察器或隔离转发路径中，且绝不能读取响应体、Cookie 或 authorization 值。

已交付验证覆盖 Rust API 与配对套件、桌面配对与预填充组件测试、扩展单元测试、主 Playwright 与扩展 Playwright 套件、生产与测试扩展构建，以及完整前端与 Rust 门禁。手动 Chrome、Edge 与 Firefox 配对、嗅探、清单过滤、预填充、接管、未配对与已撤销行为，以及 Windows 安装与启动尚未执行并保持待定，因此浏览器捕获退出仍被阻塞。

- 上下文索引器只发现 TypeScript 模块，因此 Rust 的 `api`、`engine`、`store`、`commands` 和 harness 导航条目保持手工维护。
- 自动化与 mock 服务结果不能替代真实浏览器或 Windows 记录；待定的人工项绝不能记录为通过。
- HLS 与 DASH 下载、视频解析、Firefox for Android、发布、签名、Cookie 访问、遥测和自动远程捕获仍不在本决策范围内。
